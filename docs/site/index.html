Evidence, not vibes

One command from UPF file to verdict

The engine parses your Tcl/UPF into a command stream, builds a power-intent object graph, then dispatches 74 deterministic rules against it. Findings are sorted by severity, gated by policy, and exportable for CI — text, JSON, JUnit or a self-contained HTML report.

  • ▸ Line-level provenance on every finding
  • ▸ Baseline snapshots + gate policies (--baseline --gate STRICT)
  • ▸ Semantic diff between UPF revisions
