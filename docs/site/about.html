About

Power intent deserves
the same rigor as RTL.

UPF-Insight is the power-intent sibling of the Ṛta / sdc-tools constraint validator — a family of tools that treat design intent as a first-class, verifiable artifact.

∅

No LLMs in the analysis path

The engine is a deterministic parser, model builder and rule dispatcher. Identical input always yields the identical verdict — on your machine, today and five years from now.

⌖

Every finding traces to a line

Rule codes UPF-001… carry provenance: file, line number, layer and severity. You can act on every report without hunting for context.

◫

Honest support boundaries

"No errors" never means "power proven correct". Results carry explicit trust statuses so you always know what was checked — and what wasn't.

How it works

Three deterministic stages

  1. Preprocess. Tcl/UPF source becomes a typed command stream — malformed syntax caught at the door (UPF-006).
  2. Build. The command stream constructs a power-intent object graph: domains, supply sets, strategies, switches, PSTs.
  3. Dispatch. 74 registered rules run against the graph. Handler exceptions are contained; findings are sorted deterministically.
