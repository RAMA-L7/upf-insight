This document is generated from the registry module. Every rule has a stable code, a severity, a layer, a description, and a `test_ref` naming the regression test that proves it fires or stays quiet.

**77 rules registered** · codes UPF-001..UPF-100 with intentional gaps (007-009, 017-019, 026-029, 048-049, 055-059, 066-069, 088-089). The gaps are unused code space reserved by the layered allocation, not missing rules.

**Layer legend:** `SYNTAX` · `REFERENCE` · `SUPPLY_DOMAIN` · `PST` · `STRATEGY` · `SUPPLY` · `DESIGN`

**Context legend:** `UPF_ONLY` (provable from the UPF alone) · `NETLIST_REQUIRED` (needs netlist/RTL context - advisory without it) · `PARTIAL` (structural evidence only)

Every registered rule has a handler: `upf-insight rules audit` and `tests/test_rule_audit.py` both enforce registry/handler equality, so there are no dormant codes. A rule whose handler raises is reported as an internal error with `support=NOT_VALIDATED` - the engine never lets a crashed rule read as a clean bill of health.
